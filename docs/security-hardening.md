# 本地保险库安全加固

## 凭据与加密

- 新建空间与改密要求 6–16 个字符，必须同时包含 ASCII 数字和计算器符号；允许 `+ - * / ( ) . % ^ !` 及对应的 `− × ÷` 输入。
- 配置时将 `− × ÷` 统一为 `- * /`。旧版 4–16 位凭据继续支持解锁、验证和改密，不强制重建已有保险库。
- 初次配置不再预填、推荐或展示示例密码；移除输入固定序列自动创建空间的入口。
- 候选解锁表达式在异步验证期间不加入历史；成功解锁时清空计算历史。验证失败的正常计算仍可进入历史。
- 应用内连续尝试达到 5 次后冷却 30 秒，随后指数递增，最高 1 小时；状态保存在本地，成功解锁后清除。取消计算不能撤销已计入的尝试。
- 新空间使用 64 MiB、3 次迭代的 Argon2id，不根据堆剩余空间静默降低参数。改密至少恢复此工作因子，并通过同目录临时文件、文件同步与原子替换更新加密头。
- SQLCipher 无法加载时拒绝打开数据库，不回退明文 SQLite。系统备份和设备迁移排除应用数据；用户主动导出的加密备份仍可使用。

应用内限速不能限制已复制到其他设备的加密头。离线抗猜测仍依赖 Argon2id 与密码本身的强度。原子替换避免半写入的加密头；未对各厂商文件系统进行断电持久性验证。

## 原件删除与授权

- 仅对选中的精确 URI 及系统提供的 MediaStore 映射执行删除，不通过名称、文件大小、Picker 数字 ID 或路径猜测原件。
- “删除原件”模式使用系统文档选择器请求读写授权。
- Android 10 支持恢复式授权后的删除重试，Android 11 及以上支持系统批量删除确认。
- 系统返回成功后逐项查询验证，权限拒绝、空查询对象和未知提供方异常均不会被当作删除成功。
- 可重新授权的原件自动显示引导，并定位到原 URI；同名副本不视为原件。正确重选后最多自动重试一次，仍失败则保留未确认状态。
- 取消授权会保留原件并报告结果。无法识别的云端或只读来源提示前往来源应用处理。

普通删除不保证覆盖闪存物理数据，也不会清理其他应用的缩略图、回收站、历史导出或云端副本。提示中的“已验证删除”仅指对应原件的提供方查询结果。

## Release 体积

开启 R8 和资源裁剪，生成四种 ABI 的独立完整 APK，同时保留通用 APK 给旧客户端回退。新客户端自动选择设备支持的架构。不通过移除数据库加密或密码派生算法缩减体积。

Release 另启用原生库压缩：安装时由 Android 解压当前设备所需的 ABI，不要求应用自行解压或下载库。这样减少 APK 下载体积，但安装时需要解压步骤，并占用对应原生库的提取空间。

原版 APK 为 70,500,182 字节，其中 DEX 占 45,718,336 字节，原生库占 21,646,664 字节；主要问题为 release 未开启裁剪。

第一轮签名通用包为 14,891,847 字节，减少约 78.9%。其中 DEX 为 2,420,644 字节，压缩后的原生库为 9,701,699 字节；8 个原生库解压后的 SHA-256 均与原版一致。

第二轮按架构打包，并精确排除未使用的 Bouncy Castle Picnic 数据表，避免每台手机携带其他架构和无关算法的数据。APK 签名证书、包名和版本号保持不变，尚未发布至 GitHub。

第二轮同时压缩 DEX，ARM64 包降到 5,230,703 字节。第三轮压缩内置图片、开启 PNG crunch 并排除未使用的证书提示文本，当前最终大小如下：

| 安装包 | 字节 | 十进制 MB |
| --- | ---: | ---: |
| ARM64 | 4,116,250 | 4.12 |
| 32 位 ARM | 3,706,714 | 3.71 |
| x86 | 4,160,810 | 4.16 |
| x86_64 | 4,378,600 | 4.38 |
| 通用兼容包 | 11,367,729 | 11.37 |

每个架构包都是独立完整安装包；新客户端优先下载匹配架构，旧客户端仍能使用通用包。所有产物签名一致，各自原生库与原版解压后的 SHA-256 一致，Picnic 数据表已移除。压缩后 DEX 为 1,227,573 字节。

两张 JPEG 从 1,152,648 字节降至 106,826 字节：横幅为 960×536、92,895 字节，计算器图为 512×512、13,931 字节，编码质量均为 82。原图备份在 `artifacts/image-originals/`，候选图生成后已人工检查。10 张 PNG 的预乘透明度像素哈希与压缩前一致，即渲染内容不变。ARM64 当前资源总计 266,133 字节，原生库 2,451,074 字节。

## 验证与真机验收

自动测试：`./gradlew.bat :app:testDebugUnitTest --offline --no-daemon`。覆盖强密码与旧凭据兼容、凭据历史、SQLCipher 缺失、重启后的限速、精确原件删除、部分失败及授权后核验。

完整单元与 Robolectric/Compose 测试 60 项通过，含架构优先级、通用包回退、架构包缓存恢复及地址/摘要检查；签名 release APK、独立 AAB 构建及完整 `lintRelease` 通过。Lint 仍有 100 条警告，主要为依赖更新、未使用资源和样式建议，未通过屏蔽检查来消除警告。

第三轮图片压缩后已复跑 60 项测试、APK 构建及完整 Lint，均通过；本轮未重新生成 AAB。最新 APK 和匹配的 mapping 保存在 `artifacts/android/image-optimized/`。

真机仍需分别在 Android 10、Android 11 及以上验证：本地照片与文档、相同名称不同目录、取消系统确认、只读来源、重新授权、锁屏及后台返回。对 release APK 还应完成建库、导入、锁定、解锁、预览、改密和备份恢复的冒烟测试。
