# Xome 计算器 · 图形工作台

## 入口和边界

伪装计算器顶部曲线图标 → 图形工作台；按系统返回键或页内返回返回原计算器。图形工作台只处理普通数学表达式，不触发私密空间解锁。无网络请求、无新运行时三方依赖。实验公式和上次选择的模式保存在应用本地 `xome_graph_studio` SharedPreferences 中，与加密空间头、密码和文件数据分离。

## 已实现的绘图模式

- **2D 曲线**：最多三条 `y=f(x)`，可平移、缩放、双击复位、单击读出坐标和数值导数/切线。`t` 与 `a` 可驱动动态函数。
- **物理波形**：傅里叶谐波、拍频等时变函数的多曲线合成；示波器风格辅助网格，主波形显示峰峰值 `P-P` 与均方根 `RMS`（不强加电压单位）。
- **参数曲线**：`x(u), y(u)`，含李萨如、轨迹等预设。
- **极坐标**：`r(u)`，保持 X/Y 轴等比例，含玫瑰线与螺线。
- **向量场**：`P(x,y), Q(x,y)`，用有限密度箭头显示方向。
- **3D 曲面**：`z=f(x,y)`，OpenGL ES 2.0 顶点光照，支持单指旋转、双指缩放、复位。
- **3D 空间曲线**：`x(u), y(u), z(u)`，可旋转/缩放；非法采样点自动断线。

以上均为**真实计算和绘制**，不是播放演示 GIF。原有数学计算器按键、历史、DEG/RAD、隐形解锁、加密空间行为不做修改。

## 公式语法

- 变量：`x`, `y`, `u`/`theta`, `t`, `a`。绘图三角函数默认使用**弧度**。
- 运算：`+ - * / ^`、括号、隐式乘法，如 `2x`, `2(x+1)`。
- 函数：`sin/cos/tan`, `asin/acos/atan`, `sinh/cosh/tanh`, `sinc`, `sqrt`, `abs`, `exp`, `ln/log`, `floor/ceil`, `min/max/pow` 等，以实际解析器为准。
- 输入限制：192 字符及嵌套深度限制；编译错误显示在对应公式输入框下方，不在绘图回路反复解析。

## 设计与性能策略

- 视觉：沿用 Xome 玄黑、铜色、灰白与薄荷绿主题。主角为实时画布，分类与预设为次级；36/40/48dp 的点击区和单行可滚动公式编辑。
- 状态：三段视图（2D / 波形 / 3D），预设切换即时联动公式，修改后自动取消不再匹配的预设解释；关闭和后台切换均保存公式，配置变化恢复绘图入口和上次模式。
- 2D：Compose Canvas 按视口像素预算采样，排除非有限值与明显跳变，避免画出越过奇点的错误连线。
- 3D：OpenGL ES 2，采用 `GLSurfaceView.RENDERMODE_WHEN_DIRTY` 和专用 GL 线程，网格为 46×46，复用原生 FloatBuffer 以减少动画期间频繁分配；使用平滑法线与深度缓冲。
- 动画：`withFrameNanos` 根据画面需要推进时间，只在播放时更新；后台停止动画，GL 视图在 Activity 的 START/STOP 生命周期中恢复与暂停。
- 手势：视口变换提取为可测试的纯函数，缩放保持手指焦点的世界坐标，极坐标锁定等比例。

## 验收与限制

- 单元测试覆盖解析器、全部图形预设、视口平移/缩放及 Compose 公式编辑/保存/错误提示/模式切换。
- Android 14 x86_64 模拟器（1080×2400）：实际启动 2D、波形、3D 曲面/3D 曲线，检查手势与播放状态；720×1600、360dpi（约 320dp 宽）下截图核对标题、按钮、画布与输入区域，并恢复系统屏幕配置。
- 只提供数值采样和绘制；**不宣称包含 MathStudio 全部符号计算/CAS、方程求解、3D 隐式曲面或大型数据统计工具**。这几个属于后续独立模块，不混在本次绘图扩展中。
